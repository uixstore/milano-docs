Your homepage is the first page visitors see. Milano doesn't include a dedicated homepage template — instead, you create a standard WordPress page and build its content with Elementor.

## Set a static homepage

By default, WordPress shows your latest blog posts on the front page. To use a static page instead:

1. Go to **Settings → Reading**.
2. Under **Your homepage displays**, select **A static page**.
3. In the **Homepage** dropdown, pick the page you want as your front page.
4. Click **Save Changes**.

[WordPress documentation: Reading Settings](https://wordpress.org/documentation/article/reading-settings/)

## Build your homepage with Elementor

Milano is designed for Elementor. The fastest way to build a homepage:

1. Go to **Pages → All Pages** and open your homepage.
2. Click **Edit with Elementor**.
3. Use Milano's Elementor widgets to build sections (see table below).
4. Click **Publish** when done.

| Section           | Widgets to use                                      |
| ----------------- | --------------------------------------------------- |
| Hero              | **Slideshow**, **Banner Image**                     |
| Featured products | **Product Grid**, **Product Carousel**              |
| Categories        | **Category Grid**, **Category Carousel**            |
| Promotions        | **Banner Image**, **Banner Image Carousel**         |
| Features          | **Icon Box**, **Icon Box Carousel**                 |
| Testimonials      | **Testimonial Carousel**, **Testimonial Slideshow** |
| Blog posts        | **Blog Posts**                                      |
| Instagram feed    | **Instagram Grid**, **Instagram Carousel**          |
| FAQ               | **FAQ**                                             |
| Map               | **Mapbox**                                          |

## Start from a demo

The fastest way to a complete homepage is to import a demo:

1. Go to **Milano → Dashboard → Demo**.
2. Pick a demo that matches your store.
3. Click **Import**.

The demo gives you a fully designed homepage you can customize. Edit it with Elementor to replace the content with your own.

## Per-page settings

When editing your homepage with Elementor, open **Page Settings** (gear icon in the top-left corner) to configure:

- **Page Header** — show or hide the banner area on this page.
- **Transparent Header** — use a transparent header that overlays the hero section. See [Transparent header](../header/transparent-header/).
