Pages are static content like your homepage, about page, or contact page. Unlike blog posts, pages don't have categories or tags, and they don't appear in chronological order.

## Create a new page

1. Go to **Pages → Add New** in your WordPress admin.
2. Enter a title for your page.
3. Add your content using the block editor or click **Edit with Elementor** to build with Elementor.
4. Set a **Featured Image** (optional — some page layouts use it).
5. Click **Publish**.

[WordPress documentation: Create a Page](https://wordpress.org/documentation/article/pages-screen/)

## Edit a page

1. Go to **Pages → All Pages**.
2. Hover over the page you want to edit.
3. Click **Edit** to open the full editor, or click the page title.

## Quick edit

Quick Edit lets you change common settings without opening the full editor.

1. Go to **Pages → All Pages**.
2. Hover over the page and click **Quick Edit**.
3. Change any of these:
   - **Title** — the page title.
   - **Slug** — the URL part (e.g., `about-us` for `yoursite.com/about-us/`).
   - **Status** — Published, Draft, Pending Review, or Private.
   - **Template** — Milano uses the default page template. No custom templates are included.
   - **Parent** — nest this page under another page to create a hierarchy.
   - **Order** — a number that controls the page order in menus and lists.
4. Click **Update**.

## Delete a page

1. Go to **Pages → All Pages**.
2. Hover over the page and click **Trash**.

Trashed pages are kept for 30 days. To restore or permanently delete them, go to **Pages → Trash**.

## Page attributes

| Attribute    | What it does                                                                       |
| ------------ | ---------------------------------------------------------------------------------- |
| **Parent**   | Nest the page under another page. The child page's URL includes the parent's slug. |
| **Order**    | A number that controls page order in lists and menus. Lower numbers appear first.  |
| **Template** | Milano uses the default WordPress page template. No custom templates are included. |
