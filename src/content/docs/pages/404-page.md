A 404 page appears when someone visits a URL that doesn't exist — a broken link, a mistyped address, or a deleted page.

## How Milano handles 404 pages

Milano includes a default 404 page template that displays when a page is not found. The template shows a message letting visitors know the page doesn't exist, along with a link back to the homepage.

No setup is required — the 404 page works out of the box.

## What to include on a 404 page

If you want to customize the 404 page content in the future, a good 404 page should:

- Show a clear message: "Page not found" or "Sorry, that page doesn't exist."
- Include a search bar so visitors can find what they're looking for.
- Link to popular pages (homepage, shop, contact).
